# My Dotfiles

Configs for Hyprland, Mise, Rofi, and Waybar.

## Install

1. Clone: `git clone https://github.com/okawibawa/dotfiles ~/dotfiles`
2. On Arch Linux, install Stow: `sudo pacman -S stow`
3. Run: `cd ~/dotfiles && stow hypr mise rofi waybar`
